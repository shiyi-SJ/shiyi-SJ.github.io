# 阅界 · 本地阅读器

离线本地电子书阅读器 PWA：支持 **EPUB / PDF / TXT**，从手机文件夹导入，可替换阅读背景与文字、提取目录。

## 在 iPhone 上安装（3 步）

1. 用 iPhone 的 **Safari** 打开 https://shiyi-SJ.github.io/ ；
2. 点底部 **分享** 按钮 → 选择 **添加到主屏幕** ；
3. 点右上角 **添加** ，主屏幕即出现“阅界”图标，之后可像 App 一样全屏打开。

> 说明：EPUB/PDF 渲染库与字体首次使用需联网加载（之后由 Service Worker 缓存，可离线阅读已缓存书籍）；书籍文件本身只保存在手机本机（IndexedDB），不上传任何服务器。

## 功能

- 从“文件”App / 手机文件夹导入 `.epub`、`.pdf`、`.txt`
- 5 种背景主题（浅色 / 米黄 / 护眼绿 / 夜间 / 自定义），支持上传图片作背景
- 文字颜色、字号、字体（宋体 / 黑体 / 楷体）、行距、字间距可调
- EPUB 目录（nav）、PDF 书签大纲、TXT 章节正则自动提取目录，点击跳转
- 阅读进度自动保存，书架管理（删除、封面缩略图）

## 技术

- 纯前端单页应用，无后端；epub.js + pdf.js（jsDelivr CDN），IndexedDB 存储，PWA Service Worker 离线缓存。
